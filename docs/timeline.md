## 1. 三十年前（一八五五年）

| 時期 | 出来事 |
|---|---|
| 春 | ジェイムズ・アーミテージ、ロンドンの銀行で横領。判決は流刑 |
| 秋 | 囚人輸送船グローリア・スコット号、ファルマス出港。囚人38、水夫26、兵18、ほか船長・航海士3・医者・牧師・看守4。総勢九十余名 |
| 出港三週目 | プレンダーガストが計画を明かす。牧師ウィルスンは共謀者。看守2名、二等航海士、船医が買収済み |
| 決行の前日 | **水夫ハドスンが「積荷」の書付を受け取る。火薬庫への細工と、明後日の精算の約束**（秘密終幕でのみ判明） |
| 決行の夜 | 反乱。船長射殺。二十分で制圧 |
| 直後 | エヴァンズとアーミテージが虐殺を拒み、小舟へ降ろされる |
| 約一時間後 | 火薬庫爆発。船は沈没。九十一名死亡 |
| 翌朝 | 小舟の一同、海面に浮いた紙の一枚を拾う。これが「最後の一葉」 |
| 翌日 | ホットスパー号に救助される |
| 以後 | 二人は金鉱で成功。エヴァンズ→ビードウズ（ハンプシャー）、アーミテージ→トレヴァー（ノーフォーク） |

爆発の生存者は「水夫ハドスン一名」として新聞に載る。
ハドスン自身の仕込みなので、彼だけが浮く算段があった。

## 2. 二十八〜三十年の空白

- 一八五七年、トレヴァー氏がドニソープに定住。フォーダム医師の父が初診。
  右肘内側の薬品瘢痕と、索を引いた掌の胼胝を記録する（`fordham_note`）。
- 村は何も聞かなかった。それがこの事件の温床になる。
- 老トレヴァーは「最後の一葉」を手記の末尾に貼り、三十年間黙っている。
  彼が隠していたのは自分の罪ではなく、真犯人を海から引き上げてしまった事実である。

## 4. 一八七四年 十月（第二〜五章）

すべて「ホームズが電報を受け取った日」を **D日** として数える。

| 時刻 | 出来事 | 所持・位置 |
|---|---|---|
| D-6 夜 | 老トレヴァーとハドスンの言い争い。ハドスン「もう一度あれをやろう」／老人「今度こそ人が死ぬ」。ヴィクターが廊下で聞く（`victor_testimony`） | ハドスン：屋敷 |
| D-5 昼 | ハドスン、「ハンプシャーのビードウズのところへ行く」と言い残して屋敷を出る（と、家人は思っている） | 荷物袋は屋根裏に置いたまま（`hudson_kit`） |
| D-5 深夜 01:00頃 | フォーダム医師、県道で二頭立ての貸馬車とすれ違う。馬の脚に赤い土（`hired_gig`） | ビードウズ：ノーフォーク着 |
| D-5 深夜 02:07 | **干潮**（`tide_table`）。水路が通れる二時間の窓 | |
| D-5 02:00〜02:40 | 舟が一艘、記帳せずに出て戻る（`boat_log`）。舟着き場に赤い粘土（`red_clay`）、杭に船乗り結び（`sailors_knot`） | ハドスンの遺体：水路の曲がり角へ |
| D-4 朝 | **ビードウズ、現金と旅券を持って自邸を出奔** | ハンプシャー |
| D-4 昼 | ビードウズ、ハンプシャーから書付を投函 | |
| D-2 夕 | 老トレヴァーが書付を読み、卒中で倒れる（`cipher_note` / `trevor_stroke`） | |
| D 夕 | ホームズに電報。夜行で出発 | |
| D+1 深夜 | ホームズ到着。**調査2か所**（雨） | |
| D+1 04:18 | 老トレヴァー死亡。金庫から手記（`trevor_memoir`） | |
| D+1 明け方 | 手記の回想。**同行者選択** | |
| D+1 朝 | 書付を解読（`cipher_solved`）。ハンプシャーへ電報 | |
| D+1 昼過ぎ | 執事から返電。「主人は四日前の朝より不在」 | |
| D+1 夕（干潮） | 水路を捜索。ハドスンの遺体発見。腰に庭の鉄柵 | |
| D+1 日没前 | 舟着き場で**最終選択** | |

### 順序の要点

ハドスンが屋敷を出たのは D-5。徒歩と鉄道でハンプシャーに着くのは
早くて D-4 の夕方である。**ビードウズが逃げたのは D-4 の朝**で、
ハドスンが着くより前だ。

つまりビードウズは、ハドスンが来ることを知っていて、
かつ **ハドスンが来ないことも知っていた**。これが決め手になる。

### 未入手のものを終幕に出さない

`final_beddoes_2` の本文は `dynamicText` で、実際に持っている証拠だけを提示する。
`tests/story-state.test.ts` がこれを検査する。
たとえば `attic` を調べていない周回で「ハドスンの荷物」を差し出す本文は出ない。
