# 舞台の物理モデル

演出より物理を優先する。ここに書いた接続と距離で成立しない行動は、
本文ではなく舞台設備か行動のほうを変えて解決する。

## 1. 広域

```
        ノーフォーク（ドニソープ村）
        ┌──────────────────────────┐
        │  駅 ──1マイル── 村 ──1マイル── トレヴァー邸 │
        │                              │            │
        │                          （屋敷の裏手）    │
        │                              ↓            │
        │                          舟着き場          │
        │                              ↓            │
        │                       水路（葦の間の細い溝）  │
        │                              ↓            │
        │                            外海            │
        └──────────────────────────┘

              ～ 約150マイル 南 ～

        ハンプシャー（ビードウズ邸）── サウサンプトン港
```

- 駅から屋敷まで徒歩約一マイル。雨の日は外套の裾が泥で重くなる程度の距離。
- 村と屋敷も約一マイル。夜中の往復は可能で、実際に第二章で歩く。
- ノーフォーク↔ハンプシャーは鉄道でも半日以上。**言葉だけで越えられる距離ではない。**
  だから系統2（今夜の道）が必要になる。

## 2. トレヴァー邸

```
 屋根裏  ── ハドスンの部屋（鉄の寝台・帆布の荷物袋）
   │        天窓。雨の音がいちばん近い
   │
 二階  ── 寝室（老トレヴァーが倒れている）
   │
 一階  ── 玄関広間 ─ 食堂 ─ 客間
   │        書斎（書き物机・壁の金庫・書棚）
   │
 裏手  ── 庭（古い鉄柵。一部が欠けている）
            ↓ 葦の間の小径
          舟着き場
```

- 書斎の金庫は壁付け。鍵の在処は老人が生前ヴィクターに伝えてある。
- 書き物机は三段の引き出し。三段目の底板が二重になっている。
- 屋根裏へは通常の階段で上がる。垂直の隠し経路はない。
- 庭の鉄柵は地上にあり、その一部が遺体の錘に使われた。

## 3. 沼と水路

```
      屋敷
        │
     舟着き場（板を渡しただけ。平底舟が二艘、鎖でつないである）
        │            舟番の小屋（老人が四十年、帳面をつけている）
        │
    ┌───┴─────────────────┐
    │   葦の原（人の背より高い）        │
    └───┬─────────────────┘
        │
   水路（幅は櫂の先が両岸に届くほど。深いのは中央だけ）
        │
        ├── 屋敷から約300ヤード：いちばん深い曲がり角
        │        ← ここに遺体が沈められていた
        │
      外海
```

### 潮の制約

水路は浅く、平底舟でさえ **干潮の前後およそ二時間** しか通れない。
郵便局の潮見表によれば、ハドスンが消えた夜の干潮は **午前二時七分**。

この制約が三つの役割を果たす。

1. 犯行時刻を午前二時前後に固定する。
2. 屋敷の誰も起きていない時刻であることを説明する。
3. 第三章の単独ルートで、ホームズが同じ窓を張り込む理由になる。

### 沈めたものが流れない理由

水路は葦に挟まれた溝で、深いのは中央だけ。潮が引いても
沼へ押し戻されず、外海へも流れ出さない。錘をつければその場に留まる。

## 4. 土と泥

| 場所 | 土 |
|---|---|
| ノーフォークの沼地 | 黒い泥炭土。指で潰すと葦の繊維が残る |
| ハンプシャー（白亜層） | 赤みの強い、きめの細かい粘土 |

舟着き場の板の隙間の赤い粘土（`red_clay`）と、
県道の馬の脚に跳ねた赤い土（`hired_gig`）は同じ由来である。
どちらか一方でも系統2は成立する。

## 5. 混同してはいけないもの

- **舟着き場** と **水路の曲がり角** は別の場所。前者は屋敷の裏、
  後者は300ヤード先。遺体は後者にある。
- **屋根裏のハドスンの部屋** と **書斎** は別の階。調べる動機も別。
- **書付**（ビードウズがハンプシャーから投函した警告）と
  **最後の一葉**（三十年前に海面から拾った紙）は別の紙。
  読み方の規則は同じだが、拾いはじめる位置が一語ずれている。
- **手記**（老人が自分で書いたもの）と **最後の一葉**（他人が書き、貼りつけたもの）も別物。
  手記だけでは系統1の物証にならない、という END 02 の理屈はここに依る。
